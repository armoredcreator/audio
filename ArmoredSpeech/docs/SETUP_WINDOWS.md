# Setup Windows — índice para o manual canônico

Os procedimentos vigentes para Python 3.11, .venv compartilhada, migração/verificação de ativos, comandos de teste e limpeza segura estão consolidados no [Manual canônico do ArmoredAudioLab](../../docs/ARMORED_AUDIO_LAB_OPERATIONS.md).

Não recrie a .venv validada sem necessidade. Modelos RVC, efeito sonoro, banner, storage, bancos, originais e evidências são locais e devem ser preservados. Não configure fallback de RVC/efeito em ArmoredStudio.
