# Fluxo Speech → Studio — índice para o manual canônico

O fluxo vigente é Speech completo → validação de todo o lote e de ambas as variantes → análise visual de Studio → seleção da variante já preparada → validação final → render audiovisual em uma chamada FFmpeg por vídeo.

A documentação detalhada, os módulos, o contrato v5, a matriz de rotas, a configuração Windows, os E2Es reais pós-correção e a limpeza local estão consolidados no [Manual canônico do ArmoredAudioLab](ARMORED_AUDIO_LAB_OPERATIONS.md).

Nenhum dos 17 vídeos do corpus tem banner. Os E2Es reais atuais exercitam NO_BANNER. A variante BANNER_PRESENT é coberta por testes automatizados; não alegamos E2E real com banner.
