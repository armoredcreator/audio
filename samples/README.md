# Amostras locais

Coloque aqui apenas cópias de teste autorizadas, se precisar usar esta pasta. Os vídeos não devem ser adicionados ao Git.

Preferência: mantenha os arquivos de teste fora do repositório e informe seus caminhos ao script. Para cada clipe, anote:
- ID apelido (ex.: `1046`, `291`, `12008`, `178482`);
- rótulo esperado: narração PT-BR com música, música sem fala, fala estrangeira, sem áudio;
- hash SHA-256 do original;
- duração e observações de escuta.

Nunca mova, renomeie, sobrescreva ou edite os originais do ArmoredCreator. Os resultados devem ir para uma pasta de laboratório distinta.
